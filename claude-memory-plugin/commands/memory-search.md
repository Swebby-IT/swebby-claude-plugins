# /memory-search — Ricerca Semantica nella Memoria

Esegui il comando con la query dell'utente:

```bash
claude-memory search "$ARGUMENTS"
```

Mostra i risultati formattati. Se il comando non è trovato, suggerisci `/memory-init`.
