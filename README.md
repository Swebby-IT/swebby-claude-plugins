# Swebby Claude Plugins

Marketplace di plugin per Claude Code con orchestrazione multi-agente.

## Installazione

```bash
# Aggiungi il marketplace
/plugin marketplace add mauriziostabile/swebby-claude-plugins

# Visualizza i plugin disponibili
/plugin

# Installa un plugin
/plugin install multi-agent-orchestrator@swebby-plugins
/plugin install django-orchestrator@swebby-plugins
```

## Plugin Disponibili

| Plugin | Versione | Descrizione |
|--------|----------|-------------|
| multi-agent-orchestrator | 1.2.3 | 58 agenti Sonnet specializzati (20 frontend, 20 backend, 18 specialist) |
| django-orchestrator | 1.0.4 | Orchestrazione multi-agente per Django |
