# /research — Lancia una fase di ricerca

Devi orchestrare una fase di sola ricerca. NON fare ricerca tu stesso.

## Task di ricerca

$ARGUMENTS

## Istruzioni

1. **NON navigare, leggere file o fare scraping** — delega tutto ai Researcher
2. Analizza cosa serve sapere
3. Scomponi in query/analisi atomiche indipendenti
4. Lancia Researcher Sonnet con brief strutturati:
   - **Missione**: cosa cercare/analizzare (una frase)
   - **Input**: dove cercare (file, web, codebase)
   - **Output atteso**: formato preciso della risposta
   - **Formato risposta**: RISULTATO → PROBLEMI → SUGGERIMENTI
5. Sintetizza i risultati ricevuti in un report compatto (max 15 righe)
6. Presenta il report all'utente

## Scaling
- 1 argomento → 1 Researcher
- 2-3 argomenti indipendenti → 2 Researcher in parallelo
- 4+ argomenti → max 3 Researcher

Procedi.
